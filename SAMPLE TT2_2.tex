\section*{Answer Key}

\subsection*{Question 1}
\begin{enumerate}[label=(\alph*)]
    \item Strong consistency ensures all clients see the same data immediately after an update. Eventual consistency allows for temporary inconsistencies but ensures data convergence eventually.
    \item According to CAP theorem, in a network partition scenario, a system must choose between consistency and availability; thus, guaranteeing all three (consistency, availability, and partition tolerance) simultaneously is impossible.
    \item \textbf{True.}
\end{enumerate}

\subsection*{Question 2}
\begin{enumerate}[label=(\alph*)]
    \item Advantages: Robustness, scalability; Disadvantages: Complexity in management, Security vulnerabilities.
    \item efficient \textbf{lookup and routing}
\end{enumerate}

\subsection*{Question 3}
\begin{enumerate}[label=(\alph*)]
    \item Byzantine faults involve nodes failing unpredictably or maliciously, presenting incorrect or inconsistent data, challenging consensus protocols.
    \item The Byzantine Generals Problem illustrates the challenge by showing how faulty nodes can mislead others, making consensus difficult without sufficient redundancy and verification.
\end{enumerate}

\subsection*{Question 4}
\begin{enumerate}[label=(\alph*)]
    \item The Bully Algorithm lets nodes initiate an election by sending messages to higher-ID nodes. If no response, the initiating node declares itself leader.
    \item Advantage: Simple and clear hierarchy. Disadvantage: High message overhead in large networks.
\end{enumerate}

\subsection*{Question 5}
\begin{enumerate}[label=(\alph*)]
    \item Secure cookies ensure cookies are only sent over secure HTTPS connections. The server sets this flag.
    \item \textbf{True.}
\end{enumerate}

\subsection*{Question 6}
\begin{enumerate}[label=(\alph*)]
    \item Two phases: (1) Voting (Prepare) phase, (2) Commit or Abort phase.
    \item If the coordinator crashes after sending a prepare message and before sending commit/abort, participants are left waiting indefinitely (blocked state).
\end{enumerate}
